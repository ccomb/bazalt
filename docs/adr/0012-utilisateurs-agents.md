# 0012. Un utilisateur est un agent REA

Date : 2026-11-04. Statut : accepté.

## Décision

Chaque utilisateur, humain ou agent IA, est un agent REA de la
configuration. Ses droits sont des règles (*Policy*) de la configuration.
L'authentification reste hors de Bazalt, devant lui, comme le proxy de
VoLCA.

## Conséquences

Chaque fait du journal dit quel agent l'a écrit.
